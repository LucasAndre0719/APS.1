# APS.1 — Exercícios de Modelagem UML

Este repositório reúne uma coleção de exercícios de **Análise e Projeto de Sistemas (APS)** modelados em UML, com foco em classes, atributos, operações e relacionamentos entre objetos.

Os arquivos estão no formato **`.mdj`** (projeto de modelagem UML), organizados por questão.

---

## 📚 Visão geral do conteúdo

Cada pasta representa uma questão/tema diferente:

- **Questão1 — Conta de Luz**  
  Modelagem relacionada a conta de energia e controle de gastos.
- **Questão2 — Texto de Saída**  
  Exercício introdutório de modelagem de classe para geração/representação de saída textual.
- **Questão3 — Boneco em Movimento**  
  Estrutura de classe voltada a um objeto "boneco" e possíveis ações/comportamentos.
- **Questão4 — Remédios**  
  Modelagem de medicamentos e planejamento de horários para uso.
- **Questão5 — Controle de Gastos**  
  Classes para registro de gastos e consolidação de valores.
- **Questão6 — Comanda Eletrônica**  
  Organização de comanda com itens e produtos.
- **Questão7 — Produto de Compra**  
  Modelagem de lista de compras e produtos associados.
- **Questão8 — Coleção de CDs**  
  Estrutura básica para armazenamento de CDs em coleção.
- **Questão9 — Coleção de CDs (Avançado)**  
  Extensão do tema anterior com entidades adicionais (ex.: música e músico).
- **Questão10 — Sala de Reunião**  
  Controle de salas, reuniões, agenda e funcionários.
- **Questão11 — Subclasse**  
  Exercício de herança/generalização (ex.: pessoa, cliente, funcionário, endereço e telefone).

## 🚀 Como abrir os arquivos

1. Use uma ferramenta de modelagem UML compatível com projetos `.mdj`.
2. Abra o arquivo da questão desejada.
3. Navegue pelos diagramas para analisar:
   - classes;
   - atributos e métodos;
   - associações e possíveis hierarquias.

---

## 🎯 Objetivo acadêmico

O objetivo deste material é apoiar o estudo de:

- modelagem orientada a objetos;
- abstração de domínios do mundo real;
- organização de classes e responsabilidades;
- prática de conceitos como associação, agregação e herança.
